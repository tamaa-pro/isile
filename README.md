# isile — لوحة تحكم VPN

الإصدار الحالي: **v0.3 alpha** 

لوحة ويب خفيفة لإدارة حسابات الاتصال على خادم بنظام Ubuntu، تجمع عدة بروتوكولات في مكان واحد:

| البروتوكول | بدون TLS (المنفذ 80) | مع TLS (المنفذ 443) |
|---|---|---|
| SSH + WebSocket | ✔ | ✔ |
| VLESS + WebSocket | ✔ | ✔ |
| VMess + WebSocket | ✔ | ✔ |
| Trojan + WebSocket | ✔ | ✔ |



> **تنبيه شفافية:** جميع الأكواد والملفات في هذا المستودع أُنشئت بالكامل (100%) بواسطة Claude من Anthropic، ولم تخضع لمراجعة أمنية مستقلة. راجعها قبل الاستخدام الفعلي، وجرّبها على خادم تجريبي أولاً، واستخدمها على مسؤوليتك الخاصة.

## المميزات

- لوحة ويب عبر HTTPS على المنفذ 2080، بواجهة حديثة متعددة الصفحات ومتجاوبة مع الجوال.
- **الرئيسية:** إحصائيات الخادم المباشرة (المعالج والذاكرة والقرص والشبكة مع رسوم مصغّرة)، وعدد الحسابات والمتصلين، وإجمالي الاستهلاك، والحسابات حسب البروتوكول، والأعلى استهلاكاً، والتي تنتهي قريباً، وحالة الخدمات.
- **الحسابات:** قائمة بحث وفلترة، وإنشاء وتعديل وتعطيل وحذف، ونموذج إنشاء منفصل لحسابات SSH وحسابات V2Ray.
- **الإعدادات:** تغيير كلمة المرور، والتبديل بين الثيم المظلم والمشرق، والتبديل بين العربية والإنجليزية.
- حسابات V2Ray (VLESS وVMess وTrojan) بوضع اتصال يُختار لكل حساب: TLS أو بدون TLS أو الاثنان.
- حد للترافيك وتاريخ انتهاء، ويُعطَّل الحساب تلقائياً عند تجاوز أيٍّ منهما.
- حد للأجهزة المتصلة في نفس الوقت، وعرض عدد المتصلين بكل حساب.
- روابط جاهزة للنسخ لـ VLESS وVMess وTrojan، وبيانات اتصال و Payload لـ SSH.
- شهادة Let's Encrypt تُصدر وتُجدَّد تلقائياً.

## المتطلبات

- خادم بنظام Ubuntu (+24) بصلاحيات root، ومعمارية x86_64 أو arm64.
- دومين يشير فيه سجل A إلى عنوان الخادم.
- فتح المنافذ التالية في جدار الحماية السحابي : منفذ SSH الخاص بك و 80 و 443 و 2080 و 7300.

## التثبيت

نفّذ الأمر التالي كمستخدم root:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/tamaa-pro/isile/main/install.sh)
```

سيطلب السكربت الدومين، والبريد (اختياري)، واسم المشرف وكلمة المرور. ينتهي دائماً برسالة واضحة: نجاح مع رابط اللوحة وبيانات الدخول، أو فشل مع الخطوة والسبب وآخر أسطر السجل. السجل الكامل في `/var/log/isile-install.log`.

## قائمة الإدارة والتحديث

بعد التثبيت اكتب في الطرفية:

```bash
isile
```

- `1` تعديل اسم المشرف وكلمة المرور.
- `2` عرض بيانات اللوحة (الإصدار والرابط والمنافذ وحالة الخدمات وعدد الحسابات). كلمة المرور مخزنة مشفّرة فلا تُعرض.
- `3` إلغاء تثبيت اللوحة بالكامل. تبقى الحزم المثبّتة (nginx وcertbot وغيرها).
- `4` التحديث إلى آخر إصدار من GitHub مباشرة مع الإبقاء على الحسابات وبيانات المشرف والشهادة.

## مسارات الاتصال

- `/vless` و `/vmess` و `/trojan` لحسابات V2Ray، على المنفذ 443 (TLS) أو 80 (بدون TLS).
- أي مسار آخر مع ترويسة `Upgrade: websocket` يذهب إلى SSH WebSocket.

## حد الأجهزة

- **SSH:** يُحسب بعدد الجلسات المفتوحة، وتُغلق أحدث الجلسات الزائدة تلقائياً خلال 10 ثوانٍ.
- **V2Ray:** يُحسب بعدد عناوين IP المختلفة المتصلة بالحساب، ويُحظر عنوان IP الزائد (الأحدث اتصالاً) عن المنفذين 80 و 443 لمدة 5 دقائق. لذلك يُعدّ جهازان على نفس الشبكة جهازاً واحداً، وقد يتأثر مستخدم آخر يشارك نفس عنوان IP مع الحساب المخالف أثناء مدة الحظر.
- يعتمد عدّ أجهزة V2Ray على واجهة إحصائيات Xray المتصلين، فإن لم تدعمها نسخة Xray المثبّتة يظهر العدد 0 ولا يُطبَّق الحد.

## آلية العمل

- **nginx** يستقبل المنافذ 80 و 443 و 2080 ويوزّع الطلبات داخلياً.
- **Xray** يتولى VLESS وVMess وTrojan عبر WebSocket على منافذ محلية فقط، بمدخلين لكل بروتوكول (TLS وبدون TLS) لتطبيق وضع الاتصال لكل حساب.
- **جسر SSH** يستقبل طلبات WebSocket ويمررها إلى sshd المحلي.
- حسابات SSH هي مستخدمو نظام بلا shell، ويُحسب ترافيكهم بقواعد nftables.
- ترافيك V2Ray يُقرأ من واجهة إحصائيات Xray.
- الخدمات: `vpnpanel` و `vpnbridge` و `xray` و `nginx`.

## الأمان

- كلمة مرور المشرف مشفّرة، والجلسات بكوكي آمن مع حماية CSRF، وحظر مؤقت بعد 5 محاولات دخول فاشلة.
- سياسة أمان للمحتوى (CSP) صارمة، وكل السكربتات والخطوط تُخدَم من نفس الخادم.
- كل المنافذ الداخلية مرتبطة بـ 127.0.0.1 خلف nginx، وجدار ufw مفعّل.
- يُحجب عن مستخدمي SSH و Xray الوصول إلى الشبكة الداخلية وعنوان بيانات AWS الوصفية.
- مستخدمو SSH بلا shell ولا TTY، ويُسمح لهم بتمرير المنافذ فقط.
- يُتحقق من checksum عند تنزيل Xray.
- بدون TLS تكون حركة البيانات غير مشفرة بين الجهاز والخادم، فاستخدمه فقط عند الحاجة.

## ملاحظات

- يُعاد تشغيل Xray عند تغيير حسابات V2Ray، فتنقطع اتصالات مستخدميه لثانية ثم تعود. حسابات SSH لا تتأثر.
- إن كان تطبيقك يفحص الشهادة بـ SNI مختلف عن الدومين، فعّل تجاهل التحقق من الشهادة (allowInsecure) في التطبيق.

## إخلاء المسؤولية

يُقدَّم المشروع كما هو بلا أي ضمان. المستخدم وحده مسؤول عن الالتزام بالقوانين المحلية وشروط مزود الخادم.
