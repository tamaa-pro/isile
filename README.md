# isile — لوحة تحكم VPN

الإصدار الحالي: **1.5.7**

لوحة ويب خفيفة لإدارة حسابات الاتصال على خادم Ubuntu، تجمع عدة بروتوكولات في مكان واحد.

> **تنبيه شفافية:** جميع الأكواد والملفات هنا أُنشئت بالكامل بواسطة Claude من Anthropic ولم تخضع لمراجعة أمنية مستقلة. جرّبها على خادم تجريبي أولاً واستخدمها على مسؤوليتك.

## دعم البروتوكولات والتركيبات

| البروتوكول | بدون TLS (80) | مع TLS (443) |
|---|---|---|
| SSH + WebSocket | ✔ | ✔ |
| SSH + SSL (SSH مباشر بدون WebSocket) | ✔ | ✔ |
| VLESS + WebSocket | ✔ | ✔ |
| VMess + WebSocket | ✔ | ✔ |
| Trojan + WebSocket | ✔ | ✔ |
| UDP Custom (اختياري، طرف ثالث) | منفذ UDP مستقل | — |



## المميزات الأساسية

- لوحة ويب متجاوبة مع الجوال (عربي/إنجليزي، ثيمات مظلمة ومشرقة وملوّنة) على المنفذ 2080.
- **الرئيسية:** إحصائيات الخادم المباشرة، واستهلاك الشهر، والحسابات حسب البروتوكول، وحالة الخدمات والمنافذ.
- **الحسابات:** إنشاء وتعديل وتعطيل وحذف، حد للترافيك وتاريخ انتهاء (تُعطَّل تلقائياً عند تجاوزهما)، ومؤشر اتصال، وروابط جاهزة للنسخ. في SSH عدّاد متصلين مع حد لهم.
- **صفحة عامة للحساب** (اختيارية): يرى صاحب الحساب حالته دون تسجيل دخول ولا تُعرض كلمة المرور ولا روابط الاتصال.
- **الإعدادات:** المظهر والمنطقة الزمنية، كلمة المرور، النطاق والشهادة، المكونات والبروتوكولات، سقف شهري للترافيك، رسالة ترحيب SSH، السجلات، وإعادة تشغيل اللوحة وتحديثها وإعادة ضبطها وإزالتها.
- شهادة Let's Encrypt تُصدر وتُجدَّد تلقائياً عند وجود نطاق، والتثبيت بدون نطاق مدعوم (HTTP بدون TLS) ويمكن إضافة النطاق لاحقاً.

## المتطلبات

- Ubuntu 24 أو أحدث بصلاحيات root، بمعمارية x86_64 أو arm64.
- نطاق اختياري يشير سجل A فيه إلى الخادم.
- فتح المنافذ في جدار الحماية السحابي: منفذ SSH و80 و2080 (و443 مع نطاق، ومنفذ UDP Custom إن ثُبّت). يُعدَّل ufw محلياً تلقائياً.

## التثبيت

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/tamaa-pro/isile/main/install.sh)
```

يسأل عن النطاق (Enter لتجاوزه)، والبريد، واسم المشرف وكلمة المرور. السجل الكامل في `/var/log/isile-install.log`.

## قائمة الإدارة

اكتب `isile` في الطرفية:

- `1` تعديل اسم المشرف وكلمة المرور.
- `2` عرض بيانات اللوحة (الإصدار والرابط والمنافذ والخدمات).
- `3` إلغاء تثبيت اللوحة بالكامل (تبقى الحزم المثبّتة).
- `4` التحديث إلى آخر إصدار مع الإبقاء على الحسابات والإعدادات والشهادة.

## المنافذ

80 بدون TLS، و443 مع TLS (يحتاج نطاقاً)، و2080 للوحة، ومنفذ SSH الحالي، و36712/UDP لـ UDP Custom إن ثُبّت. المنافذ ثابتة ولا تُغيَّر من اللوحة.

مسارات الاتصال: `/vless` و`/vmess` و`/trojan` لـ V2Ray، وأي مسار آخر بترويسة `Upgrade: websocket` يذهب إلى SSH WebSocket، وSSH SSL المباشر بصيغة `النطاق:المنفذ@المستخدم:كلمة_المرور`.

## آلية العمل

```
العام (80)  ──► vpnmux ──┬─ يبدأ بـ SSH- ──► sshd
                         └─ غير ذلك ───────► nginx (10080) ──► V2Ray / SSH WebSocket
العام (443) ──► stunnel (يفك TLS) ──► vpnmux ──┬─ SSH- ──► sshd
                                               └─ غير ذلك ► nginx (10443) ──► V2Ray / SSH WebSocket
```

- **vpnmux** يقرأ أول بايتات الاتصال: إن بدأت بـ `SSH-` (أو لم يُرسل شيء خلال ثانيتين) يمرّرها إلى sshd، وإلا إلى nginx.
- **stunnel** يفك TLS بشهادة النطاق ويمرّر IP العميل عبر PROXY protocol، ويعمل فقط عند وجود نطاق.
- **Xray** يتولى VLESS وVMess وTrojan على منافذ محلية، بمدخلين لكل بروتوكول (TLS وبدونه).
- حسابات SSH مستخدمو نظام بلا shell، وترافيكهم بقواعد nftables، وترافيك V2Ray من إحصائيات Xray.
- **عدّاد المتصلين:** دقيق لـ SSH فقط (عدّ عمليات sshd من `/proc`، وتُقطع الجلسات الأحدث عند تجاوز الحد). V2Ray بلا عدّاد ولا حد لأن بروتوكولاته لا تحمل هوية للجهاز؛ يبقى له مؤشر الاتصال وحد الترافيك والانتهاء.
- الخدمات: `vpnpanel` و`vpnbridge` و`vpnmux` و`vpnstunnel` و`xray` و`nginx` و`udp-custom` (إن ثُبّتت).
- **UDP Custom** حزمة خارجية مغلقة المصدر، لا تُثبَّت إلا بموافقتك: يسألك المثبّت عند أول تثبيت مع تحذير أمني (الافتراضي «لا»)، والتحديث لا يثبّتها إن لم تكن موجودة. تُثبَّت أو تُحذف لاحقاً من الإعدادات ← المكونات والبروتوكولات، وللتثبيت غير التفاعلي `ISILE_UDPC=yes`، وتعمل بمستخدم بلا صلاحيات ويحجب الجدار أي اتصال صادر جديد منها. تعطيل تركيبة أو حذف مكوّنها يمنع إنشاء حسابات جديدة بها فقط.

## الأمان

- كلمة مرور المشرف مشفّرة، والجلسات بكوكي آمن مع CSRF وتنتهي عند منتصف الليل (بحسب المنطقة الزمنية)، وحظر مؤقت بعد 5 محاولات دخول فاشلة.
- سياسة CSP صارمة وكل السكربتات والخطوط من نفس الخادم.
- المنافذ الداخلية مرتبطة بـ 127.0.0.1 وufw مفعّل. لا يقبل vpnmux ترويسة PROXY إلا من stunnel محلياً فلا يمكن تزوير IP العميل.
- يحظر vpnmux وجسر SSH مؤقتاً أي عنوان يكرّر اتصالات SSH قصيرة وفاشلة.
- يُحجب عن مستخدمي SSH و Xray الوصول إلى الشبكة الداخلية وعنوان بيانات AWS الوصفية، ومستخدمو SSH بلا shell ولا TTY ويُسمح لهم بتمرير المنافذ فقط.
- يُتحقق من checksum عند تنزيل Xray.
- بدون TLS تكون البيانات غير مشفّرة بين الجهاز والخادم.

## ملاحظات

- يُعاد تشغيل Xray عند تغيير حسابات V2Ray فتنقطع اتصالاتها لثانية، وحسابات SSH لا تتأثر.
- إن كان تطبيقك يفحص الشهادة بـ SNI مختلف عن النطاق فعّل allowInsecure.
- خيار TLS أو WebSocket أو SSL لحساب SSH يحدد بيانات الاتصال المعروضة فقط ولا يقيّد المسار فعلياً.
