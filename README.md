# isile — لوحة تحكم VPN

الإصدار الحالي: **1.9.1**

لوحة ويب خفيفة لإدارة حسابات الاتصال على خادم Ubuntu، تجمع عدة بروتوكولات في مكان واحد.

> **تنبيه شفافية:** جميع الأكواد والملفات هنا أُنشئت بالكامل بواسطة Claude من Anthropic ولم تخضع لمراجعة أمنية مستقلة. جرّبها على خادم تجريبي أولاً واستخدمها على مسؤوليتك.

## دعم البروتوكولات والتركيبات

| البروتوكول | بدون TLS | مع TLS (443) |
|---|---|---|
| SSH + WebSocket | ✔ (80) | ✔ |
| SSH + SSL (عبر stunnel) | — | ✔ |
| SSH مباشر (Direct) | ✔ (80 أو منفذ SSH) | — |
| VLESS / VMess / Trojan + WebSocket أو gRPC أو XHTTP | ✔ (80) | ✔ |
| SSH + VayDNS (اختياري، نفق DNS) | ✔ (داخل النفق) | — |
| VLESS / VMess / Trojan + VayDNS (اختياري) | ✔ (داخل النفق) | ✔ (داخل النفق) |
| SSH + SlowDNS (اختياري، نفق DNS لتطبيقات SlowDNS) | ✔ (داخل النفق) | — |
| SSH + UDP Custom (اختياري، طرف ثالث) | منفذ UDP مستقل | — |

## المميزات الأساسية

- لوحة ويب متجاوبة مع الجوال (عربي/إنجليزي، ثيمات مظلمة ومشرقة وملوّنة)، على منفذ خاص بها أو على نطاق فرعي عبر 443.
- **الرئيسية:** إحصائيات الخادم المباشرة، واستهلاك الشهر، والحسابات حسب البروتوكول، وحالة الخدمات والمنافذ.
- **الحسابات:** إنشاء وتعديل وتعطيل وحذف، حد للترافيك وتاريخ انتهاء (تُعطَّل تلقائياً عند تجاوزهما)، ومؤشر اتصال، وروابط جاهزة للنسخ. في SSH عدّاد متصلين مع حد لهم.
- **صفحة عامة للحساب** (اختيارية): يرى صاحب الحساب حالته دون تسجيل دخول ولا تُعرض كلمة المرور ولا روابط الاتصال.
- **الإعدادات:** المظهر والمنطقة الزمنية، كلمة المرور والتحقق بخطوتين ومدة الجلسة، النطاق والنطاق الفرعي للوحة ومنفذها، المكونات والبروتوكولات، سقف شهري للترافيك، رسالة ترحيب SSH، ما يراه زائر النطاق، السجلات، وإعادة تشغيل اللوحة وتحديثها وإعادة ضبطها وإزالتها.
- **المكونات الاختيارية** (UDP Custom وVayDNS وSlowDNS) لا تُثبَّت افتراضياً، وتُضاف وتُحذف من الإعدادات ← المكونات والبروتوكولات.
- شهادة Let's Encrypt تُصدر وتُجدَّد تلقائياً عند وجود نطاق. التثبيت بدون نطاق مدعوم (HTTP بدون TLS، أو شهادة ذاتية التوقيع للوحة) ويمكن إضافة النطاق لاحقاً.

## المتطلبات

- Ubuntu 24 أو أحدث بصلاحيات root، بمعمارية x86_64 أو arm64.
- نطاق اختياري يشير سجل A فيه إلى الخادم.
- فتح المنافذ في جدار الحماية السحابي: منفذ SSH و80 ومنفذ اللوحة (و443 مع نطاق، ومنفذ UDP Custom وUDP 53 إن ثُبّتا). يُعدَّل ufw محلياً تلقائياً.

## التثبيت

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/tamaa-pro/isile/main/install.sh)
```

يسأل أولاً عن النسخة: **آخر نسخة مستقرة** (موصى بها) أو **آخر نسخة عامة** (أحدث التعديلات وقد لا تكون مستقرة). ثم النطاق (Enter لتجاوزه) والنطاق الفرعي للوحة والبريد ومنفذ اللوحة واسم المشرف وكلمة المرور. السجل الكامل في `/var/log/isile-install.log`.

## الفروع والتحديث

- `latest-stable-version`: آخر نسخة مستقرة، لا تتحدث إلا بعد انتهاء اختبار التعديلات.
- `main`: آخر نسخة عامة، فيها أحدث التعديلات وقد تحتوي أخطاء.

يُسأل عن النسخة المطلوبة عند التحديث من الطرفية (`isile update` أو `isile update stable|latest`) أو من الإعدادات ← النظام، وتبقى الحسابات والإعدادات والشهادة.

## قائمة الإدارة

اكتب `isile` في الطرفية:

- `1` تعديل اسم المشرف وكلمة المرور، و`2` التحقق بخطوتين.
- `3` تغيير النطاق، و`4` النطاق الفرعي للوحة، و`5` منفذ اللوحة.
- `6` عرض بيانات اللوحة، و`7` إدارة خدمات اللوحة، و`10` إعادة تشغيل اللوحة.
- `8` إعادة ضبط اللوحة، و`9` حذفها بالكامل (تبقى الحزم المثبّتة).
- `11` التحديث.

## المنافذ

80 بدون TLS، و443 مع TLS (يحتاج نطاقاً)، ومنفذ اللوحة (الافتراضي 2096، ولا يُستخدم إذا فُعّل نطاق فرعي للوحة عبر 443)، ومنفذ SSH الحالي، و36712/UDP لـ UDP Custom، و53/UDP لـ VayDNS وSlowDNS (يُحوَّل داخلياً). منافذ 80 و443 ثابتة، ومنفذ اللوحة يُغيَّر من الإعدادات أو من `isile`.

مسارات الاتصال: `/vless` و`/vmess` و`/trojan` لـ WebSocket، و`/vless-xhttp` و`/vmess-xhttp` و`/trojan-xhttp` لـ XHTTP، وأسماء الخدمة `vless-grpc` و`vmess-grpc` و`trojan-grpc` لـ gRPC، وأي مسار آخر بترويسة `Upgrade: websocket` يذهب إلى SSH WebSocket، وSSH المباشر وSSL بصيغة `النطاق:المنفذ@المستخدم:كلمة_المرور`.

## آلية العمل

```
العام (80)  ──► vpnmux ──┬─ يبدأ بـ SSH- ──► sshd
                         ├─ PRI (HTTP/2، أي gRPC) ► nginx (10081) ──► V2Ray gRPC
                         └─ غير ذلك ───────► nginx (10080) ──► V2Ray (WebSocket/XHTTP) / SSH WebSocket
العام (443) ──► stunnel (يفك TLS) ──► vpnmux ──┬─ SSH- ──► sshd
                                               ├─ PRI (HTTP/2، أي gRPC) ► nginx (10442) ──► V2Ray gRPC
                                               └─ غير ذلك ► nginx (10443) ──► V2Ray (WebSocket/XHTTP) / SSH WebSocket
UDP 53 ──► موزّع DNS ──┬─ VayDNS ──► SSH / V2Ray
                       └─ SlowDNS ──► SSH
```

- **vpnmux** يقرأ أول بايتات الاتصال: إن بدأت بـ `SSH-` (أو لم يُرسل شيء خلال ثانيتين) يمرّرها إلى sshd، وإلا إلى nginx.
- **stunnel** يفك TLS بشهادة النطاق ويمرّر IP العميل عبر PROXY protocol، ويعمل فقط عند وجود نطاق.
- **Xray** يتولى VLESS وVMess وTrojan على منافذ محلية، بمدخلين لكل بروتوكول (TLS وبدونه).
- حسابات SSH مستخدمو نظام بلا shell، وترافيكهم بقواعد nftables، وترافيك V2Ray من إحصائيات Xray.
- **عدّاد المتصلين:** دقيق لـ SSH فقط (عدّ عمليات sshd من `/proc`، وتُقطع الجلسات الأحدث عند تجاوز الحد). V2Ray بلا عدّاد ولا حد لأن بروتوكولاته لا تحمل هوية للجهاز؛ يبقى له مؤشر الاتصال وحد الترافيك والانتهاء.
- الخدمات: `vpnpanel` و`vpnmux` و`nginx` دائماً، و`vpnbridge` و`vpnstunnel` و`xray` و`udp-custom` و`vpn-udpgw` و`vaydns` و`slowdns` بحسب المثبّت منها.
- **UDP Custom** حزمة خارجية مغلقة المصدر، لا تُثبَّت إلا بموافقتك من الإعدادات ← المكونات والبروتوكولات بعد تحذير أمني (أو `ISILE_UDPC=yes` للتثبيت غير التفاعلي). تعمل بمستخدم بلا صلاحيات ويحجب الجدار أي اتصال صادر جديد منها، ويُثبَّت معها `badvpn-udpgw` لتمرير UDP داخل نفق SSH.
- **VayDNS وSlowDNS** نفقا DNS مفتوحا المصدر (SlowDNS بنمط dnstt لتطبيقاته)، لكل منهما نطاق نفق خاص يحتاج سجل NS يشير إلى الخادم.
- تعطيل تركيبة أو حذف مكوّنها يمنع إنشاء حسابات جديدة بها فقط.

## الأمان

- كلمة مرور المشرف مشفّرة، والجلسات بكوكي آمن مع CSRF وتنتهي عند منتصف الليل (بحسب المنطقة الزمنية، أو دائمة بخيار)، وحظر مؤقت بعد 5 محاولات دخول فاشلة، وتحقق بخطوتين اختياري.
- سياسة CSP صارمة وكل السكربتات والخطوط من نفس الخادم.
- المنافذ الداخلية مرتبطة بـ 127.0.0.1 وufw مفعّل. لا يقبل vpnmux ترويسة PROXY إلا من stunnel محلياً فلا يمكن تزوير IP العميل.
- يحظر vpnmux وجسر SSH مؤقتاً أي عنوان يكرّر اتصالات SSH قصيرة وفاشلة.
- يُحجب عن مستخدمي SSH و Xray الوصول إلى الشبكة الداخلية وعنوان بيانات AWS الوصفية، ومستخدمو SSH بلا shell ولا TTY ويُسمح لهم بتمرير المنافذ فقط.
- يُتحقق من checksum عند تنزيل Xray وVayDNS.
- بدون TLS تكون البيانات غير مشفّرة بين الجهاز والخادم.

## ملاحظات

- يُعاد تشغيل Xray عند تغيير حسابات V2Ray فتنقطع اتصالاتها لثانية، وحسابات SSH لا تتأثر.
- إن كان تطبيقك يفحص الشهادة بـ SNI مختلف عن النطاق فعّل allowInsecure.
- نوع النقل (WebSocket أو gRPC أو XHTTP) لحساب V2Ray يُختار عند الإنشاء ويمكن تغييره من التعديل، ويعمل على 80 بدون TLS وعلى 443 مع TLS. يحتاج gRPC وXHTTP إلى عميل يدعمهما (مثل v2rayN وv2rayNG وStreisand وSing-box).
- خيار TLS أو WebSocket أو SSL لحساب SSH يحدد بيانات الاتصال المعروضة فقط ولا يقيّد المسار فعلياً.
